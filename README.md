# AUREON Estates

A luxury real estate website concept focused on premium properties, modern architecture, and high-end living experiences.

## Overview

AUREON Estates is designed as a cinematic real estate experience rather than a traditional property listing website. The goal is to create an emotional connection with visitors through elegant visuals, smooth animations, and immersive storytelling.

---

## Features

- Cinematic video hero section
- Smooth scrolling experience
- Luxury property showcase
- Interactive property gallery
- Animated floor plans
- 3D building previews
- Hover-expand property cards
- Luxury agent profiles
- Responsive design
- SEO optimized

---
